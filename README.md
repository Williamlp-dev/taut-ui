## Overview

**Taut UI** is a copy-paste React component library built on [Base UI](https://base-ui.com/) and [Tailwind CSS v4](https://tailwindcss.com/). It brings tactile spring motion, corner morphing, and ripple feedback using pure CSS with zero external animation dependencies.

For AI agents, documentation is available at [taut-ui.com/llms.txt](https://taut-ui.com/llms.txt).
