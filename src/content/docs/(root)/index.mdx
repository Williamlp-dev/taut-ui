**taut ui** is an open-source component library for React 19 applications, built on [Base UI](https://base-ui.com/) and [Tailwind CSS v4](https://tailwindcss.com/).

Instead of static, rigid interfaces, its components feel tactile and responsive. Each one has subtle corner-radius morphing on interaction, physical spring motion, and pointer ripples, all without an external motion library.

## Key Features

- **Tactile feedback:** Spring physics, press and selection shape morphing, and pointer ripples are built into each component.
- **Zero motion runtime:** Powered by standard CSS `linear()` spring curves and the Web Animations API, with no animation libraries to install.
- **Built on Base UI:** Accessible, unstyled headless primitives and flexible `render` prop composition out of the box.
- **Code you own:** Distributed through the `shadcn` CLI directly into your project. Every component, variant, and helper lives in your codebase as clean TypeScript.
