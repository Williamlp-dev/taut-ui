## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionPanel,
  AccordionTrigger,
} from "@/components/ui/accordion"
```

```tsx
<Accordion defaultValue={["item-1"]}>
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionPanel>
      Yes. It adheres to the WAI-ARIA design pattern and is fully keyboard navigable.
    </AccordionPanel>
  </AccordionItem>
  <AccordionItem value="item-2">
    <AccordionTrigger>Is it animated?</AccordionTrigger>
    <AccordionPanel>
      Yes. Panel height, corner morphing, and indicator rotation all animate with spring motion.
    </AccordionPanel>
  </AccordionItem>
</Accordion>
```

## API Reference

### Accordion

Wraps `Accordion.Root` from Base UI. Manages open state and keyboard navigation across items.

| Prop            | Type                             | Default | Description                                                          |
| --------------- | -------------------------------- | ------- | -------------------------------------------------------------------- |
| `multiple`      | `boolean`                        | `false` | Whether multiple items can be open at the same time                  |
| `value`         | `unknown[]`                      | -       | Controlled array of currently open item values                       |
| `defaultValue`  | `unknown[]`                      | -       | Initial array of open item values when uncontrolled                  |
| `onValueChange` | `(value: unknown[]) => void`     | -       | Called when the open items change                                    |
| `loopFocus`     | `boolean`                        | `true`  | Whether keyboard focus loops from the last item back to the first    |
| `disabled`      | `boolean`                        | `false` | Disables all items within the accordion                              |
| `...props`      | Base UI Accordion Root props     | -       | All other Accordion Root props are supported                         |

### AccordionItem

A single collapsible section with segmented surface styling and corner morphing.

| Prop        | Type                          | Default | Description                                    |
| ----------- | ----------------------------- | ------- | ---------------------------------------------- |
| `value`     | `unknown`                     | -       | Unique identifier for the item                 |
| `disabled`  | `boolean`                     | `false` | Disables this individual item                  |
| `className` | `string`                      | -       | Additional CSS classes                         |
| `...props`  | Base UI Accordion Item props  | -       | All standard accordion item props              |

### AccordionTrigger

The interactive header button that toggles the item's panel. Includes a ripple effect and rotating chevron indicator.

| Prop        | Type                            | Description                             |
| ----------- | ------------------------------- | --------------------------------------- |
| `className` | `string`                        | Additional CSS classes                  |
| `...props`  | Base UI Accordion Trigger props | All standard accordion trigger props    |

### AccordionPanel

The collapsible content container with animated height and opacity transitions. Also exported as `AccordionContent`.

| Prop        | Type                          | Description                           |
| ----------- | ----------------------------- | ------------------------------------- |
| `className` | `string`                      | Additional CSS classes                |
| `...props`  | Base UI Accordion Panel props | All standard accordion panel props    |
