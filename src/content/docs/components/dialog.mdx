## Usage

```tsx
import {
  Dialog,
  DialogClose,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogPanel,
  DialogPopup,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog"
```

```tsx
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogPopup>
    <DialogHeader>
      <DialogTitle>Edit workspace</DialogTitle>
      <DialogDescription>Update your workspace settings.</DialogDescription>
    </DialogHeader>
    <DialogPanel>{/* content */}</DialogPanel>
    <DialogFooter>
      <DialogClose>Cancel</DialogClose>
    </DialogFooter>
  </DialogPopup>
</Dialog>
```

## API Reference

### Dialog

Re-exports `Dialog.Root` from `@base-ui/react/dialog`.

| Prop           | Type                      | Default | Description                                       |
| -------------- | ------------------------- | ------- | ------------------------------------------------- |
| `open`         | `boolean`                 | -       | Controlled open state                             |
| `defaultOpen`  | `boolean`                 | `false` | Initial uncontrolled open state                   |
| `onOpenChange` | `(open: boolean) => void` | -       | Called when the open state changes                |
| `modal`        | `boolean \| "trap-focus"` | `true`  | Blocks outside interaction and traps focus        |

### DialogPopup / DialogContent

Composes `DialogPortal`, `DialogBackdrop`, `DialogViewport`, and `Dialog.Popup`.

| Prop                 | Type                 | Default | Description                                        |
| -------------------- | -------------------- | ------- | -------------------------------------------------- |
| `showCloseButton`    | `boolean`            | `false` | Renders a top-right ghost close button             |
| `fullscreenOnMobile` | `boolean`            | `false` | Expands to full screen on viewports below `sm`     |
| `closeProps`         | `Dialog.Close.Props` | -       | Props forwarded to the built-in close button       |
| `portalProps`        | `Dialog.Portal.Props`| -       | Props forwarded to the internal `DialogPortal`     |
| `className`          | `string`             | -       | Additional CSS classes                             |

### DialogPanel

Scrollable body container with overscroll containment and thin scrollbar styling.

| Prop        | Type                 | Default | Description                                 |
| ----------- | -------------------- | ------- | ------------------------------------------- |
| `render`    | `React.ReactElement` | -       | Custom element to render instead of `<div>` |
| `className` | `string`             | -       | Additional CSS classes                      |

### DialogHeader / DialogIcon / DialogTitle / DialogDescription / DialogFooter / DialogTrigger / DialogClose

Composable header, centered icon slot (`DialogIcon`), accessible typography, and action footer primitives.
