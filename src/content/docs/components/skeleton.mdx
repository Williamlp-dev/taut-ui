## API Reference

### Skeleton

Renders a `<div>` placeholder with a pulse animation and solid tonal background.

| Prop        | Type                          | Default | Description                     |
| ----------- | ----------------------------- | ------- | ------------------------------- |
| `className` | `string`                      | -       | Sizing, border-radius, and layout classes |
| `...props`  | `React.ComponentProps<"div">` | -       | All standard `<div>` attributes |
