## API

### `Skeleton`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | `—` | Additional CSS classes merged with the default pulse-animation styles. |
| `...props` | `React.ComponentProps<"div">` | `—` | All standard `<div>` HTML attributes are forwarded to the underlying element. |
