## API Reference

### Slider

Wraps Base UI `Slider.Root` along with its control, track, indicator, and thumbs.

| Prop                 | Type                                               | Default        | Description                                            |
| -------------------- | -------------------------------------------------- | -------------- | ------------------------------------------------------ |
| `value`              | `number \| readonly number[]`                      | -              | Controlled value or range tuple                        |
| `defaultValue`       | `number \| readonly number[]`                      | -              | Initial uncontrolled value or range tuple              |
| `onValueChange`      | `(value, eventDetails) => void`                    | -              | Callback fired when the slider value changes           |
| `min`                | `number`                                           | `0`            | Minimum allowed value                                  |
| `max`                | `number`                                           | `100`          | Maximum allowed value                                  |
| `step`               | `number`                                           | `1`            | Increment granularity for discrete stepping            |
| `size`               | `"xs" \| "default" \| "sm" \| "md" \| "lg" \| "xl"` | `"default"`   | Track thickness and handle proportions                 |
| `orientation`        | `"horizontal" \| "vertical"`                       | `"horizontal"` | Slider axis orientation                                |
| `showValueIndicator` | `boolean`                                          | `false`        | Shows a floating value pill while dragging or focused  |
| `showTicks`          | `boolean`                                          | `false`        | Renders step tick dots along the track (up to 50 steps) |
| `startIcon`          | `React.ReactNode`                                  | -              | Leading icon beside the track                          |
| `endIcon`            | `React.ReactNode`                                  | -              | Trailing icon beside the track                         |
| `getThumbAriaLabel`  | `(index: number) => string`                        | -              | Accessible label generator for each thumb              |
| `disabled`           | `boolean`                                          | `false`        | Disables pointer and keyboard interaction              |

### SliderValue

Renders the formatted current value(s) from Base UI `Slider.Value`. Accepts a custom render function `children?: (formattedValues, values) => React.ReactNode`.
