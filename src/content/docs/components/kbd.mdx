## Usage

```tsx

```

```tsx

  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

## API Reference

### Kbd

Renders a single styled `<kbd>` element.

| Prop        | Type                          | Description                               |
| ----------- | ----------------------------- | ----------------------------------------- |
| `className` | `string`                      | Additional CSS classes                    |
| `...props`  | `React.ComponentProps<"kbd">` | All standard kbd attributes are supported |

### KbdGroup

Groups multiple `Kbd` keys inline with consistent spacing.

| Prop        | Type                          | Description                               |
| ----------- | ----------------------------- | ----------------------------------------- |
| `className` | `string`                      | Additional CSS classes                    |
| `...props`  | `React.ComponentProps<"kbd">` | All standard kbd attributes are supported |
