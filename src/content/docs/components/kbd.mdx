## Usage

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```

```tsx
{/* Single key */}
<Kbd>⌘</Kbd>

{/* Key combination */}
<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

## API

### `Kbd`

Renders a single keyboard key with a styled key-cap appearance. Accepts all standard HTML `<kbd>` element props.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | `—` | Additional CSS classes to merge with the default styles. |
| `children` | `React.ReactNode` | `—` | The key label or symbol to display (e.g. `⌘`, `Ctrl`, `Enter`). |
| `...props` | `React.ComponentProps<"kbd">` | `—` | All other native `<kbd>` HTML attributes are forwarded to the underlying element. |

---

### `KbdGroup`

A wrapper that lays out multiple `Kbd` keys side by side with consistent spacing. Accepts all standard HTML `<kbd>` element props.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | `—` | Additional CSS classes to merge with the default styles. |
| `children` | `React.ReactNode` | `—` | One or more `Kbd` elements representing the keys in the shortcut. |
| `...props` | `React.ComponentProps<"kbd">` | `—` | All other native `<kbd>` HTML attributes are forwarded to the underlying element. |
