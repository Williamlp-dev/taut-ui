## API Reference

### Button

Renders an interactive button element with ripple feedback, optional shape morphing, and polymorphic rendering via Base UI `useRender`.

| Prop        | Type                                                                                                                          | Default     | Description                                                        |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------ |
| `variant`   | `"default" \| "filled" \| "secondary" \| "tonal" \| "elevated" \| "outline" \| "ghost" \| "text" \| "link" \| "destructive" \| "destructive-outline"` | `"default"` | Visual style variant                                               |
| `size`      | `"xs" \| "sm" \| "default" \| "md" \| "lg" \| "xl" \| "icon-xs" \| "icon-sm" \| "icon" \| "icon-md" \| "icon-lg" \| "icon-xl"` | `"default"` | Size of the button, controlling height, padding, and icon sizing   |
| `width`     | `"narrow" \| "wide"`                                                                                                          | -           | Adjusts the width of icon-only buttons                             |
| `shape`     | `"round" \| "square"`                                                                                                         | `"round"`   | Base corner radius shape                                           |
| `morph`     | `boolean`                                                                                                                     | `false`     | Enables spring corner morphing on press and when `selected`        |
| `selected`  | `boolean`                                                                                                                     | -           | Sets `aria-pressed` and `data-selected` for toggleable buttons     |
| `loading`   | `boolean`                                                                                                                     | `false`     | Shows a centered `Spinner` and disables interaction while `true`   |
| `disabled`  | `boolean`                                                                                                                     | `false`     | Disables the button natively and sets `aria-disabled`              |
| `render`    | `React.ReactElement \| ((props, state) => React.ReactElement)`                                                                | -           | Custom element to render (e.g. `<Link />` or `<a />`)              |
| `className` | `string`                                                                                                                      | -           | Additional CSS classes                                             |
| `...props`  | `React.ComponentProps<"button">`                                                                                              | -           | All standard button attributes are supported                       |

### buttonVariants

A `cva` helper exported for composing button variant styles on custom elements (pair with `tautSize` for sizing).

```tsx
import { cn } from "@/lib/utils"
import { tautSize } from "@/lib/morph"
import { buttonVariants } from "@/components/ui/button"

<a
  className={cn(buttonVariants({ variant: "outline" }), tautSize({ size: "sm" }))}
  href="/docs"
>
  Read the docs
</a>
```
