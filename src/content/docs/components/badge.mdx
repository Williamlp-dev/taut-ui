## API Reference

### Badge

Renders a styled badge element. Supports polymorphic rendering via Base UI `useRender`.

| Prop        | Type                                                                                                 | Default     | Description                                                        |
| ----------- | ---------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------ |
| `variant`   | `"default" \| "secondary" \| "outline" \| "destructive" \| "error" \| "info" \| "success" \| "warning"` | `"default"` | Visual style variant                                               |
| `size`      | `"dot" \| "sm" \| "default" \| "lg"`                                                                 | `"default"` | Size of the badge (`dot` renders a compact indicator with no text) |
| `render`    | `React.ReactElement \| ((props, state) => React.ReactElement)`                                       | -           | Custom element to render (e.g. `<a>` or `<button>`)                |
| `className` | `string`                                                                                             | -           | Additional CSS classes                                             |
| `...props`  | `React.ComponentProps<"span">`                                                                       | -           | All standard span attributes are supported                         |

### BadgeAnchor

Wrapper that positions a child `Badge` relative to another element, such as an icon button or avatar.

| Prop        | Type                                                           | Description                               |
| ----------- | -------------------------------------------------------------- | ----------------------------------------- |
| `render`    | `React.ReactElement \| ((props, state) => React.ReactElement)` | Custom element to render as the wrapper   |
| `className` | `string`                                                       | Additional CSS classes                    |
| `...props`  | `React.ComponentProps<"span">`                                 | All standard span attributes are supported |
