## Usage

```tsx
import { Badge, BadgeAnchor } from "@/components/ui/badge"
```

```tsx
{/* Standalone badge */}
<Badge variant="success">Active</Badge>

{/* Badge anchored to another element */}
<BadgeAnchor>
  <button>Notifications</button>
  <Badge size="dot" variant="destructive" />
</BadgeAnchor>
```

## API

### `Badge`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "destructive" \| "error" \| "info" \| "outline" \| "secondary" \| "success" \| "warning"` | `"default"` | Controls the color scheme of the badge. |
| `size` | `"default" \| "sm" \| "lg" \| "dot" \| "small" \| "large"` | `"default"` | Controls the size of the badge. Use `"dot"` or `"small"` for indicator-only badges with no text. |
| `render` | `React.ReactElement \| ((props, state) => React.ReactElement)` | — | Custom render function or element, forwarded to `useRender`. Allows rendering as any HTML tag or component (e.g. `<a>`, `<button>`). |
| `className` | `string` | — | Additional CSS classes merged with the variant classes. |

> [!NOTE]
> `Badge` accepts all standard `<span>` HTML attributes in addition to the props above, forwarded via `useRender` from `@base-ui/react`.

#### `variant` options

| Value | Description |
|-------|-------------|
| `default` | Primary color — high-emphasis label. |
| `secondary` | Secondary color — medium-emphasis label. |
| `destructive` | Filled destructive/red — for critical states. |
| `error` | Soft destructive background — for error states. |
| `info` | Soft info background — for informational states. |
| `success` | Soft success background — for positive states. |
| `warning` | Soft warning background — for cautionary states. |
| `outline` | Bordered, transparent fill — for low-emphasis labels. |

#### `size` options

| Value | Description |
|-------|-------------|
| `default` | Standard badge — `h-6`, suitable for text labels. |
| `sm` | Small badge — `h-5`, tighter padding. |
| `lg` | Large badge — `h-7`, slightly larger text. |
| `large` | Compact indicator — `h-4.5`, small px for counts. |
| `dot` | Dot indicator — `size-2`, no text, no padding. |
| `small` | Smaller dot indicator — `size-1.5`, no text. |

---

### `BadgeAnchor`

A wrapper that positions a `Badge` as an absolute overlay on top of a child element (e.g. an icon or button). The badge is automatically positioned at the top-end corner of the anchor.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `render` | `React.ReactElement \| ((props, state) => React.ReactElement)` | — | Custom render function or element, forwarded to `useRender`. |
| `className` | `string` | — | Additional CSS classes merged with the anchor classes. |

> [!TIP]
> Place a `Badge` with `size="dot"` or `size="small"` inside `BadgeAnchor` to get a compact notification indicator that sits flush at the corner. Larger badge sizes are offset outward from the top-start edge automatically.
