## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Popover,
  PopoverActions,
  PopoverClose,
  PopoverDescription,
  PopoverPopup,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/ui/popover"
```

```tsx
<Popover>
  <PopoverTrigger render={<Button variant="outline">Open Popover</Button>} />
  <PopoverPopup>
    <PopoverTitle>Popover Title</PopoverTitle>
    <PopoverDescription>
      Supporting copy displayed inside the popover surface.
    </PopoverDescription>
    <PopoverActions>
      <PopoverClose render={<Button size="xs" />}>Done</PopoverClose>
    </PopoverActions>
  </PopoverPopup>
</Popover>
```

## API Reference

### Popover

Alias for `Popover.Root` from Base UI. Manages open state.

| Prop           | Type                      | Default | Description                                |
| -------------- | ------------------------- | ------- | ------------------------------------------ |
| `open`         | `boolean`                 | -       | Controlled open state                      |
| `defaultOpen`  | `boolean`                 | `false` | Initial uncontrolled open state            |
| `onOpenChange` | `(open: boolean) => void` | -       | Called when the open state changes         |
| `modal`        | `boolean`                 | `false` | Blocks interaction outside when `true`     |
| `...props`     | Base UI Popover Root props | -      | All other Popover Root props are supported |

### PopoverPopup

The positioned floating container rendered inside a portal. Also exported as `PopoverContent`.

| Prop          | Type                                     | Default      | Description                                   |
| ------------- | ---------------------------------------- | ------------ | --------------------------------------------- |
| `colorScheme` | `"standard" \| "vibrant"`                | `"standard"` | Surface tint scheme                           |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"`   | Preferred side relative to the anchor         |
| `align`       | `"start" \| "center" \| "end"`           | `"center"`   | Alignment along the chosen side               |
| `sideOffset`  | `number`                                 | `8`          | Distance in pixels from the anchor            |
| `alignOffset` | `number`                                 | `0`          | Offset along the alignment axis               |
| `anchor`      | `Popover.Positioner.Props["anchor"]`     | -            | Custom anchor element                         |
| `portalProps` | `Popover.Portal.Props`                   | -            | Props forwarded to the internal portal        |
| `...props`    | Base UI Popover Popup props              | -            | All standard popover popup props              |

### PopoverTrigger / PopoverClose

Trigger and dismiss primitives wrapping Base UI `Popover.Trigger` and `Popover.Close`.

### PopoverTitle / PopoverDescription

Accessible heading and supporting description slots inside `PopoverPopup`.

### PopoverActions

Right-aligned action row at the bottom of `PopoverPopup` for buttons and `PopoverClose`.
