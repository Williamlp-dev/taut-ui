## API

### `Switch`

Extends all props from [`SwitchPrimitive.Root`](https://base-ui.com/react/components/switch).

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `icons` | `"checked" \| "both"` | `undefined` | Controls icon visibility inside the thumb. `"checked"` shows a checkmark only when on; `"both"` shows a checkmark when on and an × when off. |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Controls the overall size of the switch. |
| `checked` | `boolean` | `undefined` | The controlled checked state of the switch. |
| `defaultChecked` | `boolean` | `undefined` | The uncontrolled initial checked state of the switch. |
| `onCheckedChange` | `(checked: boolean) => void` | `undefined` | Callback fired when the checked state changes. |
| `disabled` | `boolean` | `false` | When `true`, prevents the user from interacting with the switch. |
| `name` | `string` | `undefined` | The name submitted with the form when used inside a `<form>`. |
| `value` | `string` | `undefined` | The value submitted with the form when the switch is checked. |
| `className` | `string` | `undefined` | Additional CSS class names to apply to the root element. |
