## API Reference

### Switch

Wraps Base UI `Switch.Root` and `Switch.Thumb` with Material 3 thumb scaling and optional icons.

| Prop              | Type                         | Default     | Description                                                                   |
| ----------------- | ---------------------------- | ----------- | ----------------------------------------------------------------------------- |
| `icons`           | `"checked" \| "both"`        | -           | `"checked"` shows a check when on; `"both"` also shows an `×` when off        |
| `size`            | `"sm" \| "default" \| "lg"`  | `"default"` | Overall track and thumb size preset                                           |
| `checked`         | `boolean`                    | -           | Controlled checked state                                                      |
| `defaultChecked`  | `boolean`                    | `false`     | Initial uncontrolled checked state                                            |
| `onCheckedChange` | `(checked: boolean) => void` | -           | Called when the checked state changes                                         |
| `disabled`        | `boolean`                    | `false`     | Disables interaction and dims the switch                                      |
| `className`       | `string`                     | -           | Additional CSS classes                                                        |
| `...props`        | Base UI Switch Root props    | -           | All standard switch attributes (`name`, `value`, `required`, etc.)            |
