## API Reference

### Separator

Wraps Base UI `Separator` with horizontal/vertical orientation and optional inset margins.

| Prop          | Type                         | Default        | Description                                                         |
| ------------- | ---------------------------- | -------------- | ------------------------------------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Axis of the divider line                                            |
| `inset`       | `"both" \| "start" \| "end"` | -              | Insets the divider from both ends, the leading end, or trailing end |
| `className`   | `string`                     | -              | Additional CSS classes                                              |
| `...props`    | Base UI Separator props      | -              | All standard separator attributes are supported                     |
