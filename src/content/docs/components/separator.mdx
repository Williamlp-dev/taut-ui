
```tsx

</div>
```

## API

### `Separator`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | The orientation of the separator line. |
| `inset` | `"both" \| "start" \| "end" \| undefined` | `undefined` | Adds inset margin(s) to shorten the separator. `"both"` insets both ends, `"start"` insets the leading end, `"end"` insets the trailing end. |
| `className` | `string` | `undefined` | Additional CSS class names to apply to the separator. |
