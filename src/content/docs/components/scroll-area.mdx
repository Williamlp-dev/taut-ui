## Usage

```tsx
import { ScrollArea } from "@/components/ui/scroll-area"
```

```tsx
<ScrollArea className="h-72 w-48 rounded-md border">
  <div className="p-4">
    {Array.from({ length: 50 }).map((_, i) => (
      <div key={i} className="py-1 text-sm">
        Item {i + 1}
      </div>
    ))}
  </div>
</ScrollArea>
```

## API

### `ScrollArea`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `scrollFade` | `boolean` | `false` | Adds a gradient fade mask at the edges of the viewport to indicate overflow content. |
| `scrollbarGutter` | `boolean` | `false` | Adds padding on the overflow axis when a scrollbar is present, preventing content from being obscured. |
| `fill` | `boolean` | `false` | Makes the inner content area fill the full size of the viewport (`size-full`). |
| `clampContentMinWidth` | `boolean` | `true` | Sets `minWidth: 0` on the content element to prevent it from overflowing its container. |
| `overscrollContain` | `boolean` | `false` | Applies `overscroll-contain` on the overflow axis to prevent scroll chaining to the parent. |
| `className` | `string` | — | Additional CSS classes applied to the root element. |
| `children` | `React.ReactNode` | — | The content to render inside the scroll area. |

> All other props are forwarded to the underlying `ScrollArea.Root` from `@base-ui/react/scroll-area`.

### `ScrollBar`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | The axis along which the scrollbar operates. |
| `className` | `string` | — | Additional CSS classes applied to the scrollbar element. |

> All other props are forwarded to the underlying `ScrollArea.Scrollbar` from `@base-ui/react/scroll-area`.
