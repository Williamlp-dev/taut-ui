## API Reference

### ScrollArea

Wraps Base UI `ScrollArea.Root`, `Viewport`, `Content`, both vertical and horizontal `ScrollBar`s, and `Corner`.

| Prop                   | Type                             | Default | Description                                                               |
| ---------------------- | -------------------------------- | ------- | ------------------------------------------------------------------------- |
| `scrollFade`           | `boolean`                        | `false` | Applies smooth edge fade masks along overflowing axes                     |
| `scrollbarGutter`      | `boolean`                        | `false` | Reserves padding along the scrollbar edge when content overflows          |
| `fill`                 | `boolean`                        | `false` | Expands the inner content wrapper to `size-full`                          |
| `clampContentMinWidth` | `boolean`                        | `true`  | Sets `min-width: 0` on the content element to prevent flex overflow       |
| `overscrollContain`    | `boolean`                        | `false` | Applies `overscroll-contain` on overflowing axes to stop scroll chaining  |
| `className`            | `string`                         | -       | Additional CSS classes applied to the root element                        |
| `...props`             | Base UI ScrollArea Root props    | -       | All other ScrollArea Root props are supported                             |

### ScrollBar

Overlay scrollbar track and draggable thumb that appears on hover or active scrolling.

| Prop          | Type                         | Default      | Description                                   |
| ------------- | ---------------------------- | ------------ | --------------------------------------------- |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | Scrollbar axis                                |
| `className`   | `string`                     | -            | Additional CSS classes                        |
| `...props`    | Base UI Scrollbar props      | -            | All standard scrollbar attributes             |
