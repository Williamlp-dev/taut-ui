## API Reference

### Textarea

Wraps Base UI `Field.Control` rendering a `field-sizing-content` `<textarea>` inside a styled container.

| Prop        | Type                                         | Default      | Description                                      |
| ----------- | -------------------------------------------- | ------------ | ------------------------------------------------ |
| `variant`   | `"filled" \| "outline" \| "outlined"`        | `"filled"`   | Tonal filled surface or crisp outlined surface   |
| `shape`     | `"rounded" \| "round" \| "pill" \| "square"` | `"rounded"`  | Corner radius preset                             |
| `size`      | `"sm" \| "default" \| "lg"`                  | `"default"`  | Minimum height, padding, and font size           |
| `resize`    | `"none" \| "vertical" \| "horizontal" \| "both"` | `"vertical"` | Controls the browser resize handle behavior   |
| `unstyled`  | `boolean`                                    | `false`      | Strips container chrome for custom composition   |
| `className` | `string`                                     | -            | Additional CSS classes on the outer container    |
