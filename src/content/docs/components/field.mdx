## Usage

```tsx
import {
  Field,
  FieldDescription,
  FieldError,
  FieldLabel,
} from "@/components/ui/field"
import { Input } from "@/components/ui/input"
```

```tsx
<Field name="email">
  <FieldLabel>Email</FieldLabel>
  <Input required type="email" />
  <FieldDescription>We will never share your email.</FieldDescription>
  <FieldError />
</Field>
```

## API Reference

### Field

Wraps Base UI `Field.Root`. Connects label, description, error, and control IDs automatically.

| Prop       | Type      | Default | Description                                        |
| ---------- | --------- | ------- | -------------------------------------------------- |
| `name`     | `string`  | -       | Field identifier used for `Form` error mapping     |
| `disabled` | `boolean` | `false` | Disables the field and all descendant controls     |
| `invalid`  | `boolean` | `false` | Forces invalid visual styling across child slots   |
| `validate` | `(value: unknown) => string \| string[] \| null` | - | Custom validation function |

### FieldLabel / FieldDescription / FieldError / FieldItem / FieldControl / FieldValidity

Composable primitives from `@base-ui/react/field`. `FieldDescription` automatically hides when a `FieldError` is active.
