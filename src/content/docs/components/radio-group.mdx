## Usage

```tsx
import { Radio, RadioGroup } from "@/components/ui/radio-group"
```

```tsx
<RadioGroup defaultValue="a">
  <label className="flex items-center gap-2.5 text-sm">
    <Radio value="a" />
    <span>Option A</span>
  </label>
  <label className="flex items-center gap-2.5 text-sm">
    <Radio value="b" />
    <span>Option B</span>
  </label>
</RadioGroup>
```

## API Reference

### RadioGroup

Wraps Base UI `RadioGroup`.

| Prop            | Type                                   | Default | Description                                        |
| --------------- | -------------------------------------- | ------- | -------------------------------------------------- |
| `value`         | `Value`                                | -       | Controlled selected value                          |
| `defaultValue`  | `Value`                                | -       | Initial uncontrolled selected value                |
| `onValueChange` | `(value: Value, eventDetails) => void` | -       | Callback fired when the selected option changes    |
| `name`          | `string`                               | -       | Field name submitted with a form                   |
| `disabled`      | `boolean`                              | `false` | Disables all radio buttons in the group            |
| `readOnly`      | `boolean`                              | `false` | Prevents changing the current selection            |
| `required`      | `boolean`                              | `false` | Marks the group as required for form submission    |

### Radio

Wraps Base UI `Radio.Root` (`RadioGroupItem` is also exported as an alias).

| Prop       | Type      | Default | Description                                |
| ---------- | --------- | ------- | ------------------------------------------ |
| `value`    | `Value`   | -       | Unique value represented by this radio     |
| `disabled` | `boolean` | `false` | Disables interaction for this radio button |
| `readOnly` | `boolean` | `false` | Prevents changing this radio button        |
