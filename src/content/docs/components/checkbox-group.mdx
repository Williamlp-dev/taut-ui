## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox"
import { CheckboxGroup } from "@/components/ui/checkbox-group"
```

```tsx
<CheckboxGroup defaultValue={["email"]}>
  <label className="inline-flex items-center gap-2.5 text-sm">
    <Checkbox value="email" />
    Email
  </label>
  <label className="inline-flex items-center gap-2.5 text-sm">
    <Checkbox value="slack" />
    Slack
  </label>
</CheckboxGroup>
```

## API Reference

### CheckboxGroup

Wraps Base UI `CheckboxGroup`. When a child label contains `<Checkbox parent />`, sibling items are automatically indented with subtle tree connector lines.

| Prop            | Type                        | Default | Description                                        |
| --------------- | --------------------------- | ------- | -------------------------------------------------- |
| `value`         | `string[]`                  | -       | Controlled array of checked values                 |
| `defaultValue`  | `string[]`                  | `[]`    | Initial uncontrolled array of checked values       |
| `onValueChange` | `(value: string[]) => void` | -       | Called when the group selection changes            |
| `allValues`     | `string[]`                  | -       | Full list of values required when using `parent`   |
| `disabled`      | `boolean`                   | `false` | Disables all checkboxes inside the group           |
| `className`     | `string`                    | -       | Additional CSS classes                             |
