## Usage

```tsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
```

```tsx
<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card description goes here.</CardDescription>
  </CardHeader>
  <CardContent>
    <p>Card content.</p>
  </CardContent>
  <CardFooter>
    <Button size="sm">Action</Button>
  </CardFooter>
</Card>
```

## API Reference

### Card

The root surface container. Supports polymorphic rendering via Base UI `useRender` (such as `<a>` or `<button>` for interactive cards).

| Prop          | Type                                                | Default      | Description                                           |
| ------------- | --------------------------------------------------- | ------------ | ----------------------------------------------------- |
| `variant`     | `"default" \| "elevated" \| "filled" \| "outlined"` | `"default"`  | Surface style variant                                 |
| `orientation` | `"vertical" \| "horizontal"`                        | `"vertical"` | Layout direction of the card                          |
| `ripple`      | `boolean`                                           | `false`      | Enables Material ripple feedback on pointer press     |
| `render`      | `React.ReactElement \| ((props, state) => React.ReactElement)` | - | Custom element to render (e.g. `<Link />` or `<button />`) |
| `className`   | `string`                                            | -            | Additional CSS classes                                |
| `...props`    | `React.ComponentProps<"div">`                       | -            | All standard div attributes are supported             |

### CardHeader

Grid header container that automatically accommodates a `CardTitle`, `CardDescription`, and an optional `CardAction`.

### CardTitle

Displays the heading of the card.

| Prop        | Type            | Default | Description            |
| ----------- | --------------- | ------- | ---------------------- |
| `size`      | `"md" \| "lg"`  | `"md"`  | Title typography scale |
| `className` | `string`        | -       | Additional CSS classes |

### CardDescription

Secondary muted text positioned beneath `CardTitle`.

### CardAction

Right-aligned slot inside `CardHeader` for a badge, icon, or action button.

### CardMedia

Media wrapper for `<img>` or `<video>` elements, adapting automatically when `orientation="horizontal"`.

### CardPanel / CardContent

Main body container of the card. Automatically adjusts vertical padding when paired with `CardHeader` or `CardFooter`.

### CardFooter

Horizontal action row at the bottom of the card.

### CardFrame

Outer muted frame (`rounded-3xl bg-muted p-1.5`) for grouping a `CardFrameHeader`, `CardFramePanel` (or stacked `Card`s), and `CardFrameFooter`.

### CardFrameHeader / CardFrameTitle / CardFrameDescription / CardFrameAction

Header slots rendered directly on the outer `CardFrame` surface.

### CardFramePanel / CardFrameContent

Inner elevated card surface (`rounded-2xl bg-card p-6`) inside `CardFrame`.

### CardFrameFooter

Bottom row inside `CardFrame` for metadata and actions.
