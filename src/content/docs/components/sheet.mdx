## Usage

```tsx
import {
  Sheet,
  SheetClose,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetPanel,
  SheetPopup,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet"
```

```tsx
<Sheet>
  <SheetTrigger>Open</SheetTrigger>
  <SheetPopup side="right">
    <SheetHeader>
      <SheetTitle>Edit profile</SheetTitle>
      <SheetDescription>Make changes to your profile.</SheetDescription>
    </SheetHeader>
    <SheetPanel>{/* content */}</SheetPanel>
    <SheetFooter>
      <SheetClose>Cancel</SheetClose>
    </SheetFooter>
  </SheetPopup>
</Sheet>
```

## API Reference

### Sheet

Re-exports `Dialog.Root` from `@base-ui/react/dialog`.

| Prop           | Type                      | Default | Description                                        |
| -------------- | ------------------------- | ------- | -------------------------------------------------- |
| `open`         | `boolean`                 | -       | Controlled open state                              |
| `defaultOpen`  | `boolean`                 | `false` | Initial uncontrolled open state                    |
| `onOpenChange` | `(open: boolean) => void` | -       | Callback fired when the open state changes         |
| `modal`        | `boolean \| "trap-focus"` | `true`  | Blocks outside interaction and traps focus         |
| `...props`     | Base UI Dialog Root props | -       | All other Base UI Dialog Root props are supported  |

### SheetTrigger

Button or custom element (`render`) that opens the sheet (`Dialog.Trigger`).

### SheetPopup / SheetContent

Main surface container composing `SheetPortal`, `SheetBackdrop`, `SheetViewport`, and `Dialog.Popup`.

| Prop              | Type                                     | Default     | Description                                                   |
| ----------------- | ---------------------------------------- | ----------- | ------------------------------------------------------------- |
| `side`            | `"right" \| "left" \| "top" \| "bottom"` | `"right"`   | Edge of the viewport from which the sheet enters              |
| `variant`         | `"default" \| "inset"`                   | `"default"` | Flush edge panel or floating inset surface with rounded edges |
| `showCloseButton` | `boolean`                                | `true`      | Renders a top-right ghost close button                        |
| `closeProps`      | `Dialog.Close.Props`                     | -           | Props forwarded to the built-in close button                  |
| `portalProps`     | `Dialog.Portal.Props`                    | -           | Props forwarded to the internal `SheetPortal`                 |
| `className`       | `string`                                 | -           | Additional CSS classes                                        |

### SheetHeader

Header container (`shrink-0`) for `SheetTitle` and `SheetDescription`. Supports the `render` prop.

### SheetPanel

Main content container wrapped in a `ScrollArea` by default.

| Prop         | Type                  | Default | Description                                         |
| ------------ | --------------------- | ------- | --------------------------------------------------- |
| `scrollable` | `boolean`             | `true`  | Wraps the panel in `ScrollArea` when `true`         |
| `scrollFade` | `boolean`             | `false` | Shows top/bottom fade masks when scrolling          |
| `render`     | `React.ReactElement`  | -       | Custom element to render instead of `<div>`         |
| `className`  | `string`              | -       | Additional CSS classes                              |

### SheetFooter

Bottom action container (`shrink-0`).

| Prop        | Type                  | Default     | Description                                               |
| ----------- | --------------------- | ----------- | --------------------------------------------------------- |
| `variant`   | `"default" \| "bare"` | `"default"` | Tonal footer surface (`default`) or seamless padding (`bare`) |
| `render`    | `React.ReactElement`  | -       | Custom element to render instead of `<div>`               |
| `className` | `string`              | -           | Additional CSS classes                                    |

### SheetTitle / SheetDescription / SheetClose / SheetBackdrop / SheetViewport / SheetPortal

Standard accessible `Dialog` subcomponents from `@base-ui/react/dialog`.
