## Usage

```tsx
import {
  Sheet,
  SheetTrigger,
  SheetPopup,
  SheetHeader,
  SheetTitle,
  SheetDescription,
  SheetPanel,
  SheetFooter,
  SheetClose,
} from "@/components/ui/sheet"
```

```tsx
<Sheet>
  <SheetTrigger>Open</SheetTrigger>
  <SheetPopup side="right">
    <SheetHeader>
      <SheetTitle>Edit profile</SheetTitle>
      <SheetDescription>
        Make changes to your profile here. Click save when you're done.
      </SheetDescription>
    </SheetHeader>
    <SheetPanel>
      {/* form fields or content */}
    </SheetPanel>
    <SheetFooter>
      <SheetClose>Cancel</SheetClose>
      <button type="submit">Save changes</button>
    </SheetFooter>
  </SheetPopup>
</Sheet>
```

## API

### `Sheet`

Re-exports `Dialog.Root` from `@base-ui/react/dialog`. Accepts all Base UI Dialog Root props.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — | Controlled open state of the sheet. |
| `defaultOpen` | `boolean` | `false` | Uncontrolled initial open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Callback fired when the open state changes. |
| `modal` | `boolean` | `true` | When `true`, interaction outside the sheet is blocked. |
| `dismissible` | `boolean` | `true` | When `true`, the sheet can be closed by clicking the backdrop or pressing Escape. |

---

### `SheetTrigger`

Renders the element that opens the sheet. Accepts all `Dialog.Trigger` props from Base UI.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `render` | `React.ReactElement` | — | Custom element to render as the trigger. |

---

### `SheetClose`

Renders the element that closes the sheet. Accepts all `Dialog.Close` props from Base UI.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `render` | `React.ReactElement` | — | Custom element to render as the close button. |

---

### `SheetPortal`

Re-exports `Dialog.Portal` from `@base-ui/react/dialog`. Renders its children in a portal outside the DOM tree.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `container` | `HTMLElement \| null` | `document.body` | The DOM node to portal into. |
| `keepMounted` | `boolean` | `false` | When `true`, the sheet stays mounted when closed. |

---

### `SheetBackdrop`

Renders the semi-transparent backdrop behind the sheet. Also exported as `SheetOverlay`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names merged onto the backdrop element. |

---

### `SheetViewport`

Positions the sheet within the viewport. Used internally by `SheetPopup`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `side` | `"right" \| "left" \| "top" \| "bottom"` | `"right"` | Which edge of the viewport the sheet slides in from. |
| `variant` | `"default" \| "inset"` | `"default"` | `"default"` anchors the sheet flush to the edge; `"inset"` adds padding and rounds all corners. |
| `className` | `string` | — | Additional class names for the viewport container. |

---

### `SheetPopup`

The main sheet content container. Also exported as `SheetContent`. Composes `SheetPortal`, `SheetBackdrop`, `SheetViewport`, and `Dialog.Popup`. Renders a close button in the top-right corner by default.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `side` | `"right" \| "left" \| "top" \| "bottom"` | `"right"` | Which edge the sheet slides in from. |
| `variant` | `"default" \| "inset"` | `"default"` | Visual style variant. `"inset"` adds outer padding and fully rounded corners. |
| `showCloseButton` | `boolean` | `true` | Renders a ghost icon button (×) in the top-right corner when `true`. |
| `closeProps` | `Dialog.Close.Props` | — | Props forwarded to the built-in close button. |
| `portalProps` | `Dialog.Portal.Props` | — | Props forwarded to the internal `SheetPortal`. |
| `className` | `string` | — | Additional class names for the popup element. |
| `children` | `React.ReactNode` | — | Sheet content. |

---

### `SheetHeader`

A flex column container for the sheet's title and description area.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `render` | `React.ReactElement` | — | Custom element to render instead of the default `<div>`. |

---

### `SheetFooter`

A flex container pinned to the bottom of the sheet, typically holding action buttons.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "bare"` | `"default"` | `"default"` adds a top border and muted background; `"bare"` renders without chrome. |
| `className` | `string` | — | Additional class names. |
| `render` | `React.ReactElement` | — | Custom element to render instead of the default `<div>`. |

---

### `SheetTitle`

Renders the accessible title of the sheet using `Dialog.Title`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `children` | `React.ReactNode` | — | Title text or elements. |

---

### `SheetDescription`

Renders the accessible description of the sheet using `Dialog.Description`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `children` | `React.ReactNode` | — | Description text or elements. |

---

### `SheetPanel`

A scrollable content area wrapped in a `ScrollArea`. Use this for long or variable-height content.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `scrollFade` | `boolean` | `true` | Shows a fade gradient at the scroll edges when `true`. |
| `className` | `string` | — | Additional class names for the inner content `<div>`. |
| `render` | `React.ReactElement` | — | Custom element to render instead of the default `<div>`. |
