## API Reference

### Checkbox

Wraps Base UI `Checkbox.Root` with built-in animated check and indeterminate indicators.

| Prop              | Type                       | Default | Description                                             |
| ----------------- | -------------------------- | ------- | ------------------------------------------------------- |
| `checked`         | `boolean`                  | -       | Controlled checked state                                |
| `defaultChecked`  | `boolean`                  | `false` | Initial uncontrolled checked state                      |
| `onCheckedChange` | `(checked: boolean) => void` | -     | Called when the checked state changes                   |
| `indeterminate`   | `boolean`                  | `false` | Renders the horizontal indeterminate bar                |
| `parent`          | `boolean`                  | `false` | Marks the checkbox as the parent inside `CheckboxGroup` |
| `disabled`        | `boolean`                  | `false` | Disables interaction and dims the control               |
| `className`       | `string`                   | -       | Additional CSS classes                                  |
