## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Menu,
  MenuGroup,
  MenuGroupLabel,
  MenuItem,
  MenuPopup,
  MenuSeparator,
  MenuShortcut,
  MenuTrigger,
} from "@/components/ui/menu"
```

```tsx
<Menu>
  <MenuTrigger render={<Button variant="outline">Open Menu</Button>} />
  <MenuPopup>
    <MenuGroup>
      <MenuGroupLabel>My Account</MenuGroupLabel>
      <MenuItem>
        Profile
        <MenuShortcut>⌘P</MenuShortcut>
      </MenuItem>
      <MenuItem>Settings</MenuItem>
    </MenuGroup>
    <MenuSeparator />
    <MenuItem variant="destructive">Log out</MenuItem>
  </MenuPopup>
</Menu>
```

## API Reference

### Menu

Alias for `Menu.Root` from Base UI. Manages open state and keyboard navigation.

| Prop           | Type                      | Default | Description                             |
| -------------- | ------------------------- | ------- | --------------------------------------- |
| `open`         | `boolean`                 | -       | Controlled open state                   |
| `defaultOpen`  | `boolean`                 | `false` | Initial uncontrolled open state         |
| `onOpenChange` | `(open: boolean) => void` | -       | Called when the open state changes      |
| `modal`        | `boolean`                 | `true`  | Whether the menu behaves as a modal     |
| `...props`     | Base UI Menu Root props   | -       | All other Menu Root props are supported |

### MenuPopup

Positioned floating menu surface wrapped in a portal and `ScrollArea`.

| Prop          | Type                                     | Default      | Description                                                |
| ------------- | ---------------------------------------- | ------------ | ---------------------------------------------------------- |
| `colorScheme` | `"standard" \| "vibrant"`                | `"standard"` | Surface tint scheme                                        |
| `gap`         | `boolean`                                | `false`      | Splits each `MenuGroup` into its own floating surface card |
| `scrollFade`  | `boolean`                                | `true`       | Adds fade masks while scrolling long menus                 |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"`   | Preferred side relative to the trigger                     |
| `align`       | `"start" \| "center" \| "end"`           | `"center"`   | Alignment along the chosen side                            |
| `sideOffset`  | `number`                                 | `6`          | Distance in pixels from the trigger                        |
| `portalProps` | `Menu.Portal.Props`                      | -            | Props forwarded to the internal portal                     |
| `...props`    | Base UI Menu Popup props                 | -            | All standard menu popup props                              |

### MenuItem / MenuLinkItem

Interactive menu entry with spring corner morphing on highlight.

| Prop       | Type                         | Default     | Description                                       |
| ---------- | ---------------------------- | ----------- | ------------------------------------------------- |
| `variant`  | `"default" \| "destructive"` | `"default"` | Applies destructive text styling when destructive |
| `inset`    | `boolean`                    | `false`     | Adds leading padding to align with icon items     |
| `disabled` | `boolean`                    | `false`     | Disables interaction and dims the item            |

### MenuCheckboxItem

Toggleable menu item supporting checkmark or inline `Switch` styles.

| Prop              | Type                       | Default     | Description                                   |
| ----------------- | -------------------------- | ----------- | --------------------------------------------- |
| `variant`         | `"default" \| "switch"`    | `"default"` | Renders a leading check or a trailing `Switch` |
| `checked`         | `boolean`                  | -           | Controlled checked state                      |
| `defaultChecked`  | `boolean`                  | `false`     | Initial uncontrolled checked state            |
| `onCheckedChange` | `(checked: boolean) => void` | -         | Called when the checked state changes         |

### MenuRadioGroup / MenuRadioItem

Single-selection radio items highlighting the active choice with `--menu-sel-bg`.

### MenuSub / MenuSubTrigger / MenuSubPopup

Nested submenu primitives with automatic `inline-end` positioning and trailing chevron indicator.

### MenuGroup / MenuGroupLabel / MenuSeparator / MenuShortcut / MenuTrigger / MenuPortal

Grouping, labels, dividers, keyboard shortcut hints, and trigger primitives. Also re-exported under `DropdownMenu*` aliases for shadcn compatibility.
