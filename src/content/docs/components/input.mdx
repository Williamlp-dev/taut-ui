## API Reference

### Input

Wraps Base UI `Input` inside a styled container that automatically sizes trailing buttons, badges, and leading addons.

| Prop          | Type                                          | Default     | Description                                                                   |
| ------------- | --------------------------------------------- | ----------- | ----------------------------------------------------------------------------- |
| `variant`     | `"filled" \| "outline" \| "outlined"`         | `"filled"`  | `"filled"` uses a solid tonal surface; `"outline"` adds an inset border       |
| `shape`       | `"pill" \| "round" \| "rounded" \| "square"`  | `"pill"`    | Border-radius shape of the container and nested buttons/badges                |
| `size`        | `"sm" \| "default" \| "md" \| "lg" \| number` | `"default"` | Height and padding preset; pass a number to forward the HTML `size` attribute |
| `startAddon`  | `React.ReactNode`                             | -           | Leading element (such as an icon) rendered before the input                   |
| `children`    | `React.ReactNode`                             | -           | Trailing elements (buttons, badges, icons) rendered inside the container      |
| `unstyled`    | `boolean`                                     | `false`     | Suppresses default variant styling on the outer wrapper                       |
| `nativeInput` | `boolean`                                     | `false`     | Renders a plain `<input>` instead of Base UI's `Input` primitive              |
| `className`   | `string`                                      | -           | Additional CSS classes applied to the outer container                         |
| `...props`    | Base UI Input props                           | -           | All standard input attributes (`type`, `disabled`, `aria-invalid`, etc.)      |

### inputVariants

A `cva` helper exported for composing consistent input surfaces in other components (such as `AutocompleteInput`).
