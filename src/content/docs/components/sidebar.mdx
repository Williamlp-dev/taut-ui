## Usage

```tsx
import {
  Sidebar,
  SidebarContent,
  SidebarGroup,
  SidebarGroupContent,
  SidebarGroupLabel,
  SidebarMenu,
  SidebarMenuButton,
  SidebarMenuItem,
  SidebarProvider,
} from "@/components/ui/sidebar"
```

```tsx
<SidebarProvider>
  <Sidebar>
    <SidebarContent>
      <SidebarGroup>
        <SidebarGroupLabel>Workspace</SidebarGroupLabel>
        <SidebarGroupContent>
          <SidebarMenu>
            <SidebarMenuItem>
              <SidebarMenuButton isActive>Dashboard</SidebarMenuButton>
            </SidebarMenuItem>
          </SidebarMenu>
        </SidebarGroupContent>
      </SidebarGroup>
    </SidebarContent>
  </Sidebar>
</SidebarProvider>
```

## API Reference

### SidebarProvider

Provides sidebar open/close state and mobile detection via context. Sets `--sidebar-width: 16rem` by default.

| Prop           | Type                      | Default | Description                                |
| -------------- | ------------------------- | ------- | ------------------------------------------ |
| `defaultOpen`  | `boolean`                 | `true`  | Initial uncontrolled open state            |
| `open`         | `boolean`                 | -       | Controlled desktop open state              |
| `onOpenChange` | `(open: boolean) => void` | -       | Called when the desktop open state changes |
| `className`    | `string`                  | -       | Additional CSS classes                     |

### Sidebar

Root `<aside>` container sized to `w-(--sidebar-width,16rem)`.

| Prop          | Type                              | Default       | Description                        |
| ------------- | --------------------------------- | ------------- | ---------------------------------- |
| `collapsible` | `"offcanvas" \| "icon" \| "none"` | `"offcanvas"` | Collapsible mode metadata          |
| `render`      | `React.ReactElement`              | -             | Custom element to render           |
| `className`   | `string`                          | -             | Additional CSS classes             |

### SidebarMenuButton

Interactive menu item button with solid tonal hover/active surfaces, corner morphing, and `<Ripple />`.

| Prop        | Type                 | Default | Description                                                  |
| ----------- | -------------------- | ------- | ------------------------------------------------------------ |
| `isActive`  | `boolean`            | `false` | Marks the item as active (`aria-current="page"`)             |
| `morph`     | `boolean`            | `true`  | Morphs border-radius from `rounded-lg` to `rounded-xl`       |
| `render`    | `React.ReactElement` | -       | Custom element (e.g. Next.js `<Link />`)                     |
| `className` | `string`             | -       | Additional CSS classes                                       |

### SidebarContent / SidebarGroup / SidebarGroupLabel / SidebarGroupContent / SidebarMenu / SidebarMenuItem / useSidebar

Composable layout primitives and context hook for building structured navigation trees.
