## Usage

```tsx
import {
  Drawer,
  DrawerPopup,
  DrawerTrigger,
  DrawerClose,
  DrawerHeader,
  DrawerTitle,
  DrawerDescription,
  DrawerPanel,
  DrawerFooter,
} from "@/components/ui/drawer"
```

```tsx
<Drawer>
  <DrawerTrigger>Open</DrawerTrigger>
  <DrawerPopup showBar showCloseButton>
    <DrawerHeader>
      <DrawerTitle>Title</DrawerTitle>
      <DrawerDescription>Description goes here.</DrawerDescription>
    </DrawerHeader>
    <DrawerPanel>
      <p>Main content goes here.</p>
    </DrawerPanel>
    <DrawerFooter>
      <DrawerClose>Close</DrawerClose>
    </DrawerFooter>
  </DrawerPopup>
</Drawer>
```

## API

### `Drawer`

Root component. Wraps Base UI's `Drawer.Root` and provides position context to all children.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `position` | `"bottom" \| "left" \| "right" \| "top"` | `"bottom"` | The edge from which the drawer slides in. Also sets the default swipe direction. |
| `swipeDirection` | `"down" \| "left" \| "right" \| "up"` | — | Overrides the swipe direction derived from `position`. |
| `className` | `string` | — | Passed through context and applied to the popup element. |
| ...rest | `DrawerPrimitive.Root.Props` | — | All Base UI `Drawer.Root` props (e.g. `open`, `defaultOpen`, `onOpenChange`, `modal`, `dismissible`). |

---

### `DrawerTrigger`

Button that opens the drawer. Renders a Base UI `Drawer.Trigger`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| ...props | `DrawerPrimitive.Trigger.Props` | — | All Base UI `Drawer.Trigger` props. |

---

### `DrawerClose`

Button that closes the drawer. Renders a Base UI `Drawer.Close`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| ...props | `DrawerPrimitive.Close.Props` | — | All Base UI `Drawer.Close` props. |

---

### `DrawerPortal`

Re-export of `DrawerPrimitive.Portal`. Teleports the drawer content to the document body.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| ...props | `DrawerPrimitive.Portal.Props` | — | All Base UI `Drawer.Portal` props. |

---

### `DrawerPopup`

The main drawer surface. Internally renders `DrawerPortal`, `DrawerBackdrop`, `DrawerViewport`, and `DrawerPrimitive.Popup` together as a single convenience component.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `position` | `"bottom" \| "left" \| "right" \| "top"` | context value | Overrides the position from the `Drawer` context. |
| `variant` | `"default" \| "straight" \| "inset"` | `"default"` | Visual style: `"default"` has rounded corners, `"straight"` has square corners and disables the stacking scale effect, `"inset"` floats the popup away from the edge on larger screens. |
| `showCloseButton` | `boolean` | `false` | Renders an `×` icon button in the top-right corner. |
| `showBar` | `boolean` | `false` | Renders a drag-handle bar (`DrawerBar`) inside the popup. |
| `closeProps` | `DrawerPrimitive.Close.Props` | — | Extra props forwarded to the built-in close button. |
| `portalProps` | `DrawerPrimitive.Portal.Props` | — | Extra props forwarded to the internal `DrawerPortal`. |
| ...rest | `DrawerPrimitive.Popup.Props` | — | All Base UI `Drawer.Popup` props. |

---

### `DrawerViewport`

Invisible full-screen container that positions the popup. Use directly only when composing manually without `DrawerPopup`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `position` | `"bottom" \| "left" \| "right" \| "top"` | context value | Determines layout direction. |
| `variant` | `"default" \| "straight" \| "inset"` | `"default"` | Adds inset padding when set to `"inset"`. |
| ...rest | `DrawerPrimitive.Viewport.Props` | — | All Base UI `Drawer.Viewport` props. |

---

### `DrawerBackdrop`

Semi-transparent overlay behind the popup. Fades in/out and responds to swipe progress.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| ...rest | `DrawerPrimitive.Backdrop.Props` | — | All Base UI `Drawer.Backdrop` props. |

---

### `DrawerSwipeArea`

Invisible hit area along an edge that initiates swipe-to-open from outside the popup.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `position` | `"bottom" \| "left" \| "right" \| "top"` | context value | Edge where the swipe area is placed. |
| ...rest | `DrawerPrimitive.SwipeArea.Props` | — | All Base UI `Drawer.SwipeArea` props. |

---

### `DrawerBar`

Visual drag-handle indicator (the "pill" bar). Rendered automatically by `DrawerPopup` when `showBar` is `true`, or placed manually inside a custom popup.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `position` | `"bottom" \| "left" \| "right" \| "top"` | context value | Determines bar orientation (horizontal for top/bottom, vertical for left/right) and which edge it anchors to. |
| `render` | `React.ReactElement` | — | Custom element to render instead of the default `<div>`. |
| `className` | `string` | — | Additional class names. |

---

### `DrawerHeader`

Top section for the title and description. Adds appropriate padding.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `allowSelection` | `boolean` | `false` | Enables text selection inside the header. When `true`, renders with `DrawerContent` as the inner element to allow selection on iOS. |
| `render` | `React.ReactElement` | — | Custom element to render instead of the default `<div>`. |
| `className` | `string` | — | Additional class names. |

---

### `DrawerTitle`

Accessible title rendered as a Base UI `Drawer.Title`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| ...rest | `DrawerPrimitive.Title.Props` | — | All Base UI `Drawer.Title` props. |

---

### `DrawerDescription`

Accessible description rendered as a Base UI `Drawer.Description`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| ...rest | `DrawerPrimitive.Description.Props` | — | All Base UI `Drawer.Description` props. |

---

### `DrawerPanel`

Scrollable body area for arbitrary content. Wraps content in a `ScrollArea` by default.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `scrollable` | `boolean` | `true` | Wraps content in a `ScrollArea` when `true`. Set to `false` for non-scrolling layouts. |
| `scrollFade` | `boolean` | `false` | Adds a fade gradient at the scroll edges (passed to `ScrollArea`). |
| `allowSelection` | `boolean` | `true` | Enables text selection. When `true`, renders with `DrawerContent` as the inner element. |
| `render` | `React.ReactElement` | — | Custom element to render instead of the default `<div>`. |
| `className` | `string` | — | Additional class names. |

---

### `DrawerFooter`

Sticky bottom section for action buttons.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "bare"` | `"default"` | `"default"` adds a top border and muted background; `"bare"` has no border or background. |
| `allowSelection` | `boolean` | `true` | Enables text selection inside the footer. |
| `render` | `React.ReactElement` | — | Custom element to render instead of the default `<div>`. |
| `className` | `string` | — | Additional class names. |

---

### `DrawerContent`

Re-export of `DrawerPrimitive.Content`. Use as the `render` prop on header/panel/footer to enable text selection on touch devices.

---

### `DrawerMenu`

| Prop | Type | Default | Description |
