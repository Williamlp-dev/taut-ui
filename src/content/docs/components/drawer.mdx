## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Drawer,
  DrawerClose,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerPanel,
  DrawerPopup,
  DrawerTitle,
  DrawerTrigger,
} from "@/components/ui/drawer"
```

```tsx
<Drawer>
  <DrawerTrigger render={<Button variant="outline">Open Drawer</Button>} />
  <DrawerPopup showBar>
    <DrawerHeader>
      <DrawerTitle>Title</DrawerTitle>
      <DrawerDescription>Description goes here.</DrawerDescription>
    </DrawerHeader>
    <DrawerPanel>
      <p>Main content goes here.</p>
    </DrawerPanel>
    <DrawerFooter>
      <DrawerClose render={<Button variant="ghost" />}>Close</DrawerClose>
    </DrawerFooter>
  </DrawerPopup>
</Drawer>
```

## API Reference

### Drawer

Root component wrapping Base UI `Drawer.Root` and providing edge position context to its children.

| Prop             | Type                                       | Default    | Description                                                    |
| ---------------- | ------------------------------------------ | ---------- | -------------------------------------------------------------- |
| `position`       | `"bottom" \| "top" \| "left" \| "right"`   | `"bottom"` | Edge from which the drawer slides in                           |
| `swipeDirection` | `"down" \| "up" \| "left" \| "right"`      | -          | Overrides the swipe direction inferred from `position`         |
| `open`           | `boolean`                                  | -          | Controlled open state                                          |
| `defaultOpen`    | `boolean`                                  | `false`    | Initial uncontrolled open state                                |
| `onOpenChange`   | `(open: boolean) => void`                  | -          | Called when the open state changes                             |
| `...props`       | Base UI Drawer Root props                  | -          | All other Drawer Root props are supported                      |

### DrawerPopup

The sliding surface rendered inside `DrawerPortal`, `DrawerBackdrop`, and `DrawerViewport`.

| Prop              | Type                                     | Default     | Description                                                   |
| ----------------- | ---------------------------------------- | ----------- | ------------------------------------------------------------- |
| `position`        | `"bottom" \| "top" \| "left" \| "right"` | -           | Overrides the `position` inherited from `Drawer`              |
| `variant`         | `"default" \| "straight" \| "inset"`     | `"default"` | Surface geometry (`inset` floats with rounded corners on `sm+`) |
| `showBar`         | `boolean`                                | `false`     | Renders the drag handle bar along the leading edge            |
| `showCloseButton` | `boolean`                                | `false`     | Renders a top-end close icon button                           |
| `closeProps`      | `Drawer.Close.Props`                     | -           | Props forwarded to the built-in close button                  |
| `portalProps`     | `Drawer.Portal.Props`                    | -           | Props forwarded to the internal portal                        |
| `...props`        | Base UI Drawer Popup props               | -           | All standard drawer popup props                               |

### DrawerHeader

Header region for `DrawerTitle` and `DrawerDescription`.

| Prop             | Type      | Default | Description                                        |
| ---------------- | --------- | ------- | -------------------------------------------------- |
| `allowSelection` | `boolean` | `false` | Allows text selection inside the header drag zone  |

### DrawerPanel

Main body container, wrapped in a `ScrollArea` by default.

| Prop             | Type      | Default | Description                                       |
| ---------------- | --------- | ------- | ------------------------------------------------- |
| `scrollable`     | `boolean` | `true`  | Wraps the content in a `ScrollArea`               |
| `scrollFade`     | `boolean` | `false` | Adds edge fade masks while scrolling              |
| `allowSelection` | `boolean` | `true`  | Allows text selection inside the panel            |

### DrawerFooter

Action row anchored to the bottom of the drawer.

| Prop             | Type                  | Default     | Description                                               |
| ---------------- | --------------------- | ----------- | --------------------------------------------------------- |
| `variant`        | `"default" \| "bare"` | `"default"` | `"default"` uses a contrasting footer surface; `"bare"` blends into the popup |
| `allowSelection` | `boolean`             | `true`      | Allows text selection inside the footer                   |

### DrawerTrigger / DrawerClose / DrawerTitle / DrawerDescription / DrawerBar / DrawerSwipeArea

Standard triggers, headings, drag handle bar, and edge swipe-area primitives.

### DrawerMenu Primitives

Composable touch-friendly menu items built for mobile and side drawers, all featuring spring corner morphing and ripple feedback:

- `DrawerMenu`, `DrawerMenuGroup`, `DrawerMenuGroupLabel`, `DrawerMenuSeparator`
- `DrawerMenuItem` (`variant?: "default" | "destructive"`)
- `DrawerMenuTrigger` (opens a nested `Drawer` with a trailing chevron)
- `DrawerMenuCheckboxItem` (`variant?: "default" | "switch"`)
- `DrawerMenuRadioGroup`, `DrawerMenuRadioItem`
