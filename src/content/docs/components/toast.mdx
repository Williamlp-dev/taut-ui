## Usage

Mount `ToastProvider` (and optionally `AnchoredToastProvider`) once in your root layout:

```tsx
import { AnchoredToastProvider, ToastProvider } from "@/components/ui/toast"

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <ToastProvider position="bottom-right">
      <AnchoredToastProvider>{children}</AnchoredToastProvider>
    </ToastProvider>
  )
}
```

Trigger notifications anywhere using `toastManager`:

```tsx
import { toastManager } from "@/components/ui/toast"

toastManager.add({
  title: "Changes saved",
  description: "Your workspace preferences have been updated.",
  type: "success",
})
```

## API Reference

### ToastProvider

Wraps Base UI `Toast.Provider` and renders the floating toast stack viewport.

| Prop          | Type                                                                                           | Default          | Description                                      |
| ------------- | ---------------------------------------------------------------------------------------------- | ---------------- | ------------------------------------------------ |
| `position`    | `"top-left" \| "top-center" \| "top-right" \| "bottom-left" \| "bottom-center" \| "bottom-right"` | `"bottom-right"` | Viewport corner or edge where toasts stack       |
| `timeout`     | `number`                                                                                       | `5000`           | Auto-dismiss duration in milliseconds            |
| `limit`       | `number`                                                                                       | `3`              | Maximum number of visible stacked toasts         |
| `portalProps` | `Toast.Portal.Props`                                                                           | -                | Props forwarded to the internal `Toast.Portal`   |

### AnchoredToastProvider

Renders toasts anchored to specific DOM elements via `anchoredToastManager`.

### toastManager / anchoredToastManager

Imperative manager instances created with `Toast.createToastManager()`.

| Method                    | Description                                                      |
| ------------------------- | ---------------------------------------------------------------- |
| `add(options)`            | Creates a toast and returns its `id`                             |
| `update(id, options)`     | Updates an existing toast by `id`                                |
| `close(id)`               | Dismisses a toast by `id`                                        |
| `promise(promise, state)` | Transitions a toast through `loading`, `success`, and `error`    |
