## Usage

```tsx

  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui/table"
```

```tsx
<Table variant="card">
  <TableHeader>
    <TableRow>
      <TableHead>Name</TableHead>
      <TableHead className="text-right">Role</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>Lucas Santos</TableCell>
```

## API Reference

### Table

Renders a horizontally scrollable container (`data-slot="table-container"`) wrapping a `<table>` element.

| Prop        | Type                  | Default     | Description                                                |
| ----------- | --------------------- | ----------- | ---------------------------------------------------------- |
| `variant`   | `"default" \| "card"` | `"default"` | Flat row dividers or rounded tonal card body surface       |
| `render`    | `React.ReactElement`  | -           | Custom outer container element                             |
| `className` | `string`              | -           | Additional CSS classes applied to the `<table>` element    |

### TableHeader / TableBody / TableFooter / TableRow / TableHead / TableCell / TableCaption

Semantic HTML table subcomponents (`<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`, `<caption>`) styled for both `default` and `card` variants.
