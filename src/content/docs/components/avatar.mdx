```tsx

  Avatar,
  AvatarFallback,
  AvatarImage,
} from "@/components/ui/avatar"
```


## API Reference

### Avatar

Wraps Base UI `Avatar.Root`.

| Prop        | Type                             | Default     | Description                         |
| ----------- | -------------------------------- | ----------- | ----------------------------------- |
| `size`      | `"sm" \| "default" \| "lg" \| "xl"` | `"default"` | Avatar diameter and fallback font size |
| `className` | `string`                         | -           | Additional CSS classes              |

### AvatarImage

Wraps Base UI `Avatar.Image`. Renders the image and hides automatically while loading or on error.

| Prop                  | Type                                    | Default | Description                           |
| --------------------- | --------------------------------------- | ------- | ------------------------------------- |
| `src`                 | `string`                                | -       | Image source URL                      |
| `alt`                 | `string`                                | -       | Accessible alternative text           |
| `onLoadingStatusChange` | `(status: ImageLoadingStatus) => void` | -       | Callback fired when loading state changes |

### AvatarFallback

Wraps Base UI `Avatar.Fallback`. Displayed when the image has not loaded or failed to load.

| Prop        | Type     | Default | Description                                        |
| ----------- | -------- | ------- | -------------------------------------------------- |
| `delay`     | `number` | -       | Delay in milliseconds before showing the fallback  |
| `className` | `string` | -       | Additional CSS classes                             |

### AvatarGroup

Overlaps multiple `Avatar` elements with a cutout ring and fans them out smoothly on hover.

| Prop        | Type                                | Default     | Description                                       |
| ----------- | ----------------------------------- | ----------- | ------------------------------------------------- |
| `size`      | `"sm" \| "default" \| "lg" \| "xl"` | `"default"` | Uniform size, overlap, ring width, and hover spread |
| `className` | `string`                            | -           | Additional CSS classes                            |
