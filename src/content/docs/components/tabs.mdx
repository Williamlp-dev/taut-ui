## API Reference

### Tabs

Wraps Base UI `Tabs.Root`. Manages active tab state and layout orientation.

| Prop            | Type                         | Default        | Description                                |
| --------------- | ---------------------------- | -------------- | ------------------------------------------ |
| `value`         | `unknown`                    | -              | Controlled active tab value                |
| `defaultValue`  | `unknown`                    | -              | Initial uncontrolled active tab value      |
| `onValueChange` | `(value: unknown) => void`   | -              | Called when the active tab changes         |
| `orientation`   | `"horizontal" \| "vertical"` | `"horizontal"` | Layout direction and arrow-key navigation  |
| `className`     | `string`                     | -              | Additional CSS classes                     |
| `...props`      | Base UI Tabs Root props      | -              | All other Tabs Root props are supported    |

### TabsList

Container for `TabsTab` triggers with a built-in spring-animated `Tabs.Indicator`.

| Prop        | Type                                                                                                      | Default     | Description                                       |
| ----------- | --------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------- |
| `variant`   | `"default" \| "pill" \| "outline" \| "circular" \| "primary" \| "secondary" \| "underline" \| "clean" \| "dot"` | `"default"` | Indicator and surface style preset                |
| `stacked`   | `boolean`                                                                                                 | `false`     | Stacks icon above label vertically inside each tab |
| `className` | `string`                                                                                                  | -           | Additional CSS classes                            |
| `...props`  | Base UI Tabs List props                                                                                   | -           | All standard tabs list props                      |

### TabsTab / TabsTrigger

Interactive tab button associated with a `TabsPanel` via `value`.

| Prop        | Type                    | Default | Description                           |
| ----------- | ----------------------- | ------- | ------------------------------------- |
| `value`     | `unknown`               | -       | Identifier matching a `TabsPanel`     |
| `disabled`  | `boolean`               | `false` | Disables interaction and dims the tab |
| `className` | `string`                | -       | Additional CSS classes                |
| `...props`  | Base UI Tabs Tab props  | -       | All standard tab attributes           |

### TabsPanel / TabsContent

Content panel displayed when its `value` matches the active tab.

| Prop        | Type                     | Description                    |
| ----------- | ------------------------ | ------------------------------ |
| `value`     | `unknown`                | Identifier matching a `TabsTab` |
| `className` | `string`                 | Additional CSS classes         |
| `...props`  | Base UI Tabs Panel props | All standard panel attributes  |
