## Usage

```tsx
import {
  Command,
  CommandInput,
  CommandList,
  CommandEmpty,
  CommandGroup,
  CommandGroupLabel,
  CommandItem,
  CommandShortcut,
  CommandSeparator,
  CommandPanel,
  CommandFooter,
  CommandCollection,
  CommandDialog,
  CommandDialogTrigger,
  CommandDialogBackdrop,
  CommandDialogViewport,
  CommandDialogPopup,
  CommandDialogPortal,
  CommandCreateHandle,
} from "@/components/ui/command"
```

```tsx
<Command>
  <CommandInput placeholder="Type a command or search…" />
  <CommandPanel>
    <CommandList>
      <CommandEmpty>No results found.</CommandEmpty>
      <CommandGroup>
        <CommandGroupLabel>Suggestions</CommandGroupLabel>
        <CommandItem>
          Calendar
          <CommandShortcut>⌘K</CommandShortcut>
        </CommandItem>
        <CommandItem>Search</CommandItem>
      </CommandGroup>
      <CommandSeparator />
      <CommandGroup>
        <CommandGroupLabel>Settings</CommandGroupLabel>
        <CommandItem>Profile</CommandItem>
        <CommandItem>Billing</CommandItem>
      </CommandGroup>
    </CommandList>
    <CommandFooter>
      <span>↑↓ navigate</span>
      <span>↵ select</span>
      <span>esc close</span>
    </CommandFooter>
  </CommandPanel>
</Command>
```

### As a dialog

Wrap the command palette in `CommandDialog` to display it as a modal overlay:

```tsx
<CommandDialog>
  <CommandDialogTrigger>Open Command Palette</CommandDialogTrigger>
  <CommandDialogPopup>
    <Command>
      <CommandInput placeholder="Type a command or search…" />
      <CommandPanel>
        <CommandList>
          <CommandEmpty>No results found.</CommandEmpty>
          <CommandGroup>
            <CommandItem>Calendar</CommandItem>
            <CommandItem>Search</CommandItem>
          </CommandGroup>
        </CommandList>
      </CommandPanel>
    </Command>
  </CommandDialogPopup>
</CommandDialog>
```

## API

### `Command`

The root command palette container. Wraps the internal `Autocomplete` component with sensible command-palette defaults (`inline`, always `open`, auto-highlight enabled).

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `autoHighlight` | `"always" \| "whenOpen" \| false` | `"always"` | When to automatically highlight the first matching item. |
| `keepHighlight` | `boolean` | `true` | Whether to keep the highlighted item when the list updates. |
| `...props` | `React.ComponentProps<typeof Autocomplete>` | — | All other props are forwarded to the underlying `Autocomplete` component. |

---

### `CommandInput`

A styled search input with a leading search icon, rendered inside a padded wrapper.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `placeholder` | `string` | `undefined` | Placeholder text shown when the input is empty. |
| `variant` | `"outline" \| string` | `"outline"` | Visual variant passed to `AutocompleteInput`. |
| `className` | `string` | — | Additional class names applied to the inner `AutocompleteInput`. |
| `...props` | `React.ComponentProps<typeof AutocompleteInput>` | — | All other props are forwarded to `AutocompleteInput`. |

---

### `CommandPanel`

A styled container that wraps `CommandList` and `CommandFooter` with a card-like appearance (border, background, rounded corners).

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `React.ComponentProps<"div">` | — | All other props are forwarded to the underlying `<div>`. |

---

### `CommandList`

A scrollable list container for command items. Automatically adds padding when non-empty.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `React.ComponentProps<typeof AutocompleteList>` | — | All other props are forwarded to `AutocompleteList`. |

---

### `CommandEmpty`

Rendered when the list has no results. Displays centered muted text.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `React.ComponentProps<typeof AutocompleteEmpty>` | — | All other props are forwarded to `AutocompleteEmpty`. |

---

### `CommandGroup`

A logical grouping of related command items. Adds top margin when preceded by another group.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `React.ComponentProps<typeof AutocompleteGroup>` | — | All other props are forwarded to `AutocompleteGroup`. |

---

### `CommandGroupLabel`

A small muted label displayed above a `CommandGroup`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `React.ComponentProps<typeof AutocompleteGroupLabel>` | — | All other props are forwarded to `AutocompleteGroupLabel`. |

---

### `CommandCollection`

A direct re-export of `AutocompleteCollection`. Use it to supply a static or filtered collection of items to the command palette.

---

### `CommandItem`

An individual selectable command entry. Supports a `destructive` variant, inset alignment, disabled state, and renders a ripple effect on interaction.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `children` | `React.ReactNode` | — | Item content; can include icons and a `CommandShortcut`. |
| `data-variant` | `"destructive"` | — | Set to `"destructive"` to style the item in a destructive (red) color. |
| `data-inset` | `boolean` | — | Adds leading padding to align with items that have an icon. |
| `...props` | `React.ComponentProps<typeof AutocompleteItem>` | — | All other props are forwarded to `AutocompleteItem`. |

---

### `CommandSeparator`

A thin horizontal divider between groups or items. Automatically hidden when it is the last visible element.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `React.ComponentProps<typeof AutocompleteSeparator>` | — | All other props are forwarded to `AutocompleteSeparator`. |

---

### `CommandShortcut`

A `<kbd>` element styled for displaying keyboard shortcuts, intended to be placed inside a `CommandItem`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `React.ComponentProps<"kbd">` | — | All other props are forwarded to the underlying `<kbd>` element. |

---

### `CommandFooter`

A flex row at the bottom of `CommandPanel`, typically used to display keyboard navigation hints.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `React.ComponentProps<"div">` | — | All other props are forwarded to the underlying `<div>`. |

---

### `CommandDialog`

A re-export of `@base-ui/react/dialog`'s `Dialog.Root`. Provides the dialog open/close state context.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Uncontrolled initial open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Callback fired when the open state changes. |

---

### `CommandDialogTrigger`

A button that toggles the `CommandDialog` open/closed.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `...props` | `CommandDialogPrimitive.Trigger.Props` | — | All props are forwarded to the Base UI `Dialog.Trigger`. |

---

### `CommandDialogPopup`

The animated popup panel rendered inside the dialog portal, backdrop, and viewport. Accepts an optional `portalProps` to configure the portal.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names applied to the popup panel. |
| `children` | `React.ReactNode` | — | Content rendered inside the popup (typically a `Command`). |
| `portalProps` | `CommandDialogPrimitive.Portal.Props` | — | Optional props forwarded to the `CommandDialogPortal`. |
| `...props` | `CommandDialogPrimitive.Popup.Props` | — | All other props are forwarded to the Base UI `Dialog.Popup`. |

---

### `CommandDialogBackdrop`

A fixed, blurred semi-transparent backdrop rendered behind the dialog popup.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `CommandDialogPrimitive.Backdrop.Props` | — | All other props are forwarded to the Base UI `Dialog.Backdrop`. |

---

### `CommandDialogViewport`

A fixed full-screen viewport that centers the dialog popup.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | Additional class names. |
| `...props` | `CommandDialogPrimitive.Viewport.Props` | — | All other props are forwarded to the Base UI `Dialog.Viewport`. |

---

### `CommandDialogPortal`

A re-export of `@base-ui/react/dialog`'s `Dialog.Portal`. Renders its children outside the normal DOM tree.

---

### `CommandCreateHandle`

A re-export of `@base-ui/react/dialog`'s `Dialog.createHandle`. Use it to create an imperative handle ref for programmatically controlling the dialog.
