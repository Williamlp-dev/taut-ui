## API Reference

### NumberField

Wraps Base UI `NumberField.Root` and provides shared `variant`, `shape`, `size`, and `fieldId` context to child slots.

| Prop            | Type                                         | Default     | Description                                                |
| --------------- | -------------------------------------------- | ----------- | ---------------------------------------------------------- |
| `value`         | `number \| null`                             | -           | Controlled numeric value                                   |
| `defaultValue`  | `number`                                     | -           | Initial uncontrolled numeric value                         |
| `onValueChange` | `(value: number \| null, eventDetails) => void` | -        | Callback fired when the numeric value changes              |
| `min`           | `number`                                     | -           | Minimum allowed value                                      |
| `max`           | `number`                                     | -           | Maximum allowed value                                      |
| `step`          | `number \| "any"`                            | `1`         | Base increment/decrement step amount                       |
| `smallStep`     | `number`                                     | `0.1`       | Step amount when holding `Alt`                             |
| `largeStep`     | `number`                                     | `10`        | Step amount when holding `Shift`                           |
| `format`        | `Intl.NumberFormatOptions`                   | -           | Number formatting options (currency, percent, units, etc.) |
| `variant`       | `"filled" \| "outline" \| "outlined"`        | `"filled"`  | Surface style passed to `NumberFieldGroup`                 |
| `shape`         | `"pill" \| "round" \| "rounded" \| "square"` | `"pill"`    | Corner radius preset                                       |
| `size`          | `"sm" \| "default" \| "md" \| "lg"`          | `"default"` | Field height, padding, and stepper button size             |
| `disabled`      | `boolean`                                    | `false`     | Disables input, steppers, and scrub area                   |

### Subcomponents

- `NumberFieldGroup` — styled container inheriting `inputVariants` (can override `variant`, `shape`, `size`).
- `NumberFieldInput` — centered tabular-nums numeric input.
- `NumberFieldDecrement` / `NumberFieldIncrement` — ghost icon stepper buttons.
- `NumberFieldScrubArea` — interactive drag-to-scrub label (`label: string`) with horizontal resize cursor.
