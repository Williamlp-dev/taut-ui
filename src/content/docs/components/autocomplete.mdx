## Usage

```tsx
import {
  Autocomplete,
  AutocompleteEmpty,
  AutocompleteInput,
  AutocompleteItem,
  AutocompleteList,
  AutocompletePopup,
} from "@/components/ui/autocomplete"
```

```tsx
const fruits = ["Apple", "Banana", "Cherry", "Date", "Elderberry"]

<Autocomplete items={fruits}>
  <AutocompleteInput placeholder="Search fruits…" showClear />
  <AutocompletePopup>
    <AutocompleteEmpty>No results found.</AutocompleteEmpty>
    <AutocompleteList>
      {(fruit) => (
        <AutocompleteItem key={fruit} value={fruit}>
          {fruit}
        </AutocompleteItem>
      )}
    </AutocompleteList>
  </AutocompletePopup>
</Autocomplete>
```

## API Reference

### Autocomplete

Wraps `Autocomplete.Root` from Base UI. Manages the input value, open state, and item filtering.

| Prop              | Type                             | Default | Description                                               |
| ----------------- | -------------------------------- | ------- | --------------------------------------------------------- |
| `items`           | `readonly unknown[]`             | -       | Items (or groups) used to filter and render the list      |
| `openOnCtrlSpace` | `boolean`                        | `false` | Opens the suggestions popup when pressing `Ctrl + Space`  |
| `value`           | `string`                         | -       | Controlled input value                                    |
| `defaultValue`    | `string`                         | -       | Initial uncontrolled input value                          |
| `onValueChange`   | `(value: string) => void`        | -       | Called when the input value changes                       |
| `...props`        | Base UI Autocomplete Root props  | -       | All other Autocomplete Root props are supported           |

### AutocompleteInput

Styled input group with optional leading addon, clear button, and dropdown trigger.

| Prop           | Type                                         | Default     | Description                                       |
| -------------- | -------------------------------------------- | ----------- | ------------------------------------------------- |
| `variant`      | `"filled" \| "outline" \| "outlined"`        | `"filled"`  | Visual style variant                              |
| `shape`        | `"pill" \| "round" \| "rounded" \| "square"` | `"pill"`    | Border radius shape                               |
| `size`         | `"sm" \| "default" \| "md" \| "lg"`          | `"default"` | Size of the input and internal buttons            |
| `showTrigger`  | `boolean`                                    | `false`     | Displays a trailing chevron trigger button        |
| `showClear`    | `boolean`                                    | `false`     | Displays a clear button when the input has text   |
| `startAddon`   | `React.ReactNode`                            | -           | Leading element (such as an icon)                 |
| `triggerProps` | `Autocomplete.Trigger.Props`                 | -           | Props forwarded to the trigger button             |
| `clearProps`   | `Autocomplete.Clear.Props`                   | -           | Props forwarded to the clear button               |
| `...props`     | Base UI Autocomplete Input props             | -           | All standard autocomplete input props             |

### AutocompletePopup

Positioned dropdown container rendered inside a portal.

| Prop          | Type                                 | Default      | Description                                   |
| ------------- | ------------------------------------ | ------------ | --------------------------------------------- |
| `colorScheme` | `"standard" \| "vibrant"`            | `"standard"` | Surface tint scheme                           |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` | Preferred side relative to the input          |
| `align`       | `"start" \| "center" \| "end"`       | `"start"`    | Alignment along the chosen side               |
| `sideOffset`  | `number`                             | `6`          | Distance in pixels from the anchor            |
| `alignOffset` | `number`                             | `0`          | Offset along the alignment axis               |
| `portalProps` | `Autocomplete.Portal.Props`          | -            | Props forwarded to the internal portal        |
| `...props`    | Base UI Autocomplete Popup props     | -            | All standard autocomplete popup props         |

### AutocompleteList

Scrollable container for suggestion items. Accepts a render function or static children.

| Prop        | Type                            | Description                             |
| ----------- | ------------------------------- | --------------------------------------- |
| `className` | `string`                        | Additional CSS classes                  |
| `...props`  | Base UI Autocomplete List props | All standard autocomplete list props    |

### AutocompleteItem

An individual selectable suggestion item.

| Prop        | Type                            | Description                             |
| ----------- | ------------------------------- | --------------------------------------- |
| `value`     | `unknown`                       | The value of the item                   |
| `className` | `string`                        | Additional CSS classes                  |
| `...props`  | Base UI Autocomplete Item props | All standard autocomplete item props    |

### AutocompleteEmpty

Displays a message when no items match the current query.

| Prop        | Type                             | Description                             |
| ----------- | -------------------------------- | --------------------------------------- |
| `className` | `string`                         | Additional CSS classes                  |
| `...props`  | Base UI Autocomplete Empty props | All standard autocomplete empty props   |

### AutocompleteGroup

Groups related items together.

| Prop        | Type                             | Description                             |
| ----------- | -------------------------------- | --------------------------------------- |
| `items`     | `readonly unknown[]`             | Items that belong to this group         |
| `className` | `string`                         | Additional CSS classes                  |
| `...props`  | Base UI Autocomplete Group props | All standard autocomplete group props   |

### AutocompleteGroupLabel

Displays a label for an `AutocompleteGroup`.

| Prop        | Type                                   | Description                                  |
| ----------- | -------------------------------------- | -------------------------------------------- |
| `className` | `string`                               | Additional CSS classes                       |
| `...props`  | Base UI Autocomplete Group Label props | All standard autocomplete group label props  |

### AutocompleteCollection

Alias for `Autocomplete.Collection`. Used inside `AutocompleteGroup` to render grouped items.

### AutocompleteSeparator

A visual divider between groups or items.

### AutocompleteStatus

Live status region for async loading or result counts.

### AutocompleteTrigger / AutocompleteClear / AutocompleteValue / AutocompleteRow

Lower-level primitives re-exported for custom compositions.
