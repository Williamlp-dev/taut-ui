## API Reference

### Spinner

Renders an accessible `<svg role="status">` spinner element.

| Prop         | Type                                            | Default     | Description                                         |
| ------------ | ----------------------------------------------- | ----------- | --------------------------------------------------- |
| `size`       | `"xs" \| "sm" \| "default" \| "lg" \| "xl"`     | `"default"` | Spinner dimensions (`16px` up to `48px`, `32px` default) |
| `aria-label` | `string`                                        | `"Loading"` | Accessible status label announced to screen readers |
| `className`  | `string`                                        | -           | Additional CSS classes                              |
| `...props`   | `Omit<React.ComponentProps<"svg">, "children">` | -           | All standard `<svg>` attributes                     |
