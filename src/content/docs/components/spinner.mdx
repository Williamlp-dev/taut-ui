## API

### `Spinner`

Extends all native `<svg>` props (except `children`).

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "contained"` | `"default"` | Visual style of the spinner. `"default"` inherits the current text color; `"contained"` renders inside a secondary-colored background pill. |
| `size` | `"xs" \| "sm" \| "default" \| "lg" \| "xl"` | `"default"` | Size of the spinner. When `variant="contained"` the wrapper padding is adjusted automatically per size. |
| `aria-label` | `string` | `"Loading"` | Accessible label announced to screen readers via the wrapping `<output>` element. |
| `className` | `string` | — | Additional CSS classes merged onto the inner `<svg>` element. |
