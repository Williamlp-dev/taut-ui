## API Reference

### TooltipProvider

Re-exports `Tooltip.Provider` from `@base-ui/react/tooltip` to share hover delay across adjacent triggers.

### Tooltip

Re-exports `Tooltip.Root` from `@base-ui/react/tooltip`.

### TooltipTrigger

Element that activates the tooltip on hover or focus (`Tooltip.Trigger`). Supports `render`, `handle`, and `payload`.

### TooltipPopup / TooltipContent

Composes `Tooltip.Portal`, `Tooltip.Positioner`, `Tooltip.Popup`, and `Tooltip.Viewport`.

| Prop          | Type                                     | Default    | Description                                         |
| ------------- | ---------------------------------------- | ---------- | --------------------------------------------------- |
| `variant`     | `"plain" \| "vibrant" \| "rich"`         | `"plain"`  | Surface preset (`plain`, `vibrant`, or `rich` card) |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"top"`    | Placement side relative to the trigger              |
| `align`       | `"start" \| "center" \| "end"`           | `"center"` | Cross-axis alignment                                |
| `sideOffset`  | `number`                                 | `8`        | Distance in pixels from the trigger                 |
| `anchor`      | `Tooltip.Positioner.Props["anchor"]`     | -          | Custom anchor element or ref                        |
| `portalProps` | `Tooltip.Portal.Props`                   | -          | Props forwarded to `Tooltip.Portal`                 |
| `className`   | `string`                                 | -          | Additional CSS classes                              |

### TooltipTitle / TooltipDescription / TooltipActions

Structured subcomponents for `variant="rich"` tooltips.

### TooltipCreateHandle

Re-exports `Tooltip.createHandle` for connecting multiple `TooltipTrigger` elements to a single morphing `Tooltip`.
